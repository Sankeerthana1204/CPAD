# CPAD Assignment Draft

This folder contains a complete draft for the Cross Platform Application Development assignment.

## Scope Confirmed

- Application type: E-commerce (limited scope)
- Features in scope:
  - Login Screen
  - Main Menu (Dashboard) with item list and search
  - Item Detail Page
- User role: Customer only
- Catalog type: Single-category, simple products
- Login method: Email + Password
- Out of scope:
  - Cart, checkout, payment
  - Address and shipping
  - Order tracking and returns
- Target platform: Web browser + mobile app + backend services
- Technology alignment: Flutter + REST API + SQL DB
